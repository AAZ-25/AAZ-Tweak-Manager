# AAZ Tweak Manager

Private, portable backups for Rootless jailbreak tweaks and sources.

[English](#english) · [العربية](#العربية)

## English

### Features

- Back up selected tweaks, required dependencies, and safe public sources.
- Create standard or password-encrypted `.aaztmbackup` files.
- Import backups securely from the Files share sheet.
- Check every restore plan before making changes.
- Restore missing packages and sources without removals or downgrades.
- View one privacy-safe report for Backup, Import, and Restore.

### Compatibility

- iOS 15 or later
- Rootless jailbreak using `/var/jb`
- Sileo or Zebra with APT/dpkg
- `iphoneos-arm64`

Rootful and roothide are not supported.

### Install and use

1. Download the latest DEB from [Releases](../../releases/latest).
2. Install it with Sileo or Zebra.
3. Select tweaks, create a backup, and share it to a safe location.
4. To import, use **Share → Save to AAZ Tweak Manager** in Files.
5. Review the restore plan before confirming any restore.

### Privacy and safety

- Passwords are never stored. Tokens, private repository credentials, device identifiers, and personal files are not included.
- Private repositories may require sign-in again after transfer.
- Restore requires a separate confirmation and a fresh safety check.
- Package removals, downgrades, and unapproved actions are refused.
- Machine-readable report keys remain in English for reliable support.

## العربية

نسخ احتياطية خاصة ومحمولة لتعديلات ومصادر الجيلبريك بنظام Rootless.

### المميزات

- نسخ التعديلات المحددة واعتمادياتها والمصادر العامة الآمنة.
- إنشاء ملفات `.aaztmbackup` عادية أو مشفرة بكلمة مرور.
- استيراد النسخ بأمان من قائمة المشاركة في تطبيق الملفات.
- فحص خطة الاستعادة قبل تنفيذ أي تغيير.
- استعادة الحزم والمصادر الناقصة دون حذف أو الرجوع لإصدار أقدم.
- تقرير واحد وآمن للخصوصية لعمليات النسخ والاستيراد والاستعادة.

### التوافق

- iOS 15 أو أحدث
- جيلبريك Rootless يستخدم `/var/jb`
- Sileo أو Zebra مع APT/dpkg
- معمارية `iphoneos-arm64`

أنظمة Rootful وroothide غير مدعومة.

### التثبيت والاستخدام

1. حمّل أحدث ملف DEB من [الإصدارات](../../releases/latest).
2. ثبّته باستخدام Sileo أو Zebra.
3. اختر التعديلات، وأنشئ نسخة، ثم احفظها في مكان آمن.
4. للاستيراد، اختر **مشاركة ← حفظ في AAZ Tweak Manager** من تطبيق الملفات.
5. راجع خطة الاستعادة قبل تأكيد التنفيذ.

### الخصوصية والأمان

- لا تشمل النسخ كلمات المرور أو الرموز أو بيانات المستودعات الخاصة أو معرّفات الجهاز أو الملفات الشخصية.
- قد تحتاج إلى تسجيل الدخول مجددًا في المستودعات الخاصة بعد النقل.
- تتطلب الاستعادة تأكيدًا منفصلًا وفحص أمان جديدًا.
- يرفض التطبيق حذف الحزم أو الرجوع لإصدار أقدم أو تنفيذ إجراءات غير معتمدة.
- تبقى مفاتيح التقرير التقنية بالإنجليزية لتسهيل الدعم.
