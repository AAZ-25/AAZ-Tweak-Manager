# Third-Party References

AAZ Tweak Manager is implemented independently. No third-party source code is copied into the project.

## Research references

- Debian APT documentation for manual/automatic package state, sources, authenticated repositories, downloads, and simulation behavior.
- Sileo public source for rootless command and APT path conventions.
- IAmLazy by Lightmann as an ISC-licensed architectural reference for jailbreak package backup and restore. Its code was not incorporated.
- LiveContainer's public File Picker repair was reviewed as behavioral evidence for a DocumentsUI host-identity mismatch. The repair here was implemented independently; no LiveContainer source code was incorporated.

Apple, Debian, Sileo, Zebra, Chariz, IAmLazy, and LiveContainer are not affiliated with or endorsing this project.
